# AURA | Premium Lifestyle & Essentials

> A modern, minimalist e-commerce showcase featuring refined typography, fluid micro-interactions, responsive design, and an interactive shopping experience.

🌐 **Live Website**: [https://manmohit49.github.io/aura-ecommerce/](https://manmohit49.github.io/aura-ecommerce/)

---

## ✨ Features

- **Minimalist Aesthetic**: High-contrast, clean typography powered by *Plus Jakarta Sans* and bespoke color palettes.
- **Fluid Micro-interactions**: Smooth transitions, card hover zoom effects, and dynamic navbar state transitions on scroll.
- **Interactive Shopping Bag**: Real-time cart badge counter with animated toast feedback on quick adds.
- **Authentication Modal**:
  - Modal with slide & scale transitions.
  - Interactive password strength criteria indicators.
  - Password visibility toggle.
  - Integrated with Firebase Auth with offline demo simulation fallback.
- **Curated Collections & Signatures**: Curated product grids with tags, quick-action overlays, and lookbooks.
- **Fully Responsive**: Optimized for ultra-wide desktop monitors down to mobile devices.
- **Zero Build Dependencies**: Pure HTML5, modern ES modules, and Tailwind CSS CDN.

---

## 🛠️ Tech Stack

- **HTML5 & Modern JavaScript (ES6+ Modules)**
- **Tailwind CSS** (via CDN)
- **Google Fonts** (`Plus Jakarta Sans`)
- **FontAwesome 6** (Icons)
- **Firebase Authentication SDK 11.6.1**

---

## 🚀 Local Development

Simply open `index.html` in any modern web browser or serve via any static HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:8000` in your browser.
